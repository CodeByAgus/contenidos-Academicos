# Ciclo While

## Descripción
Ejercicios prácticos sobre la estructura de control **Ciclo While** en JavaScript.

El ciclo `while` es una estructura que repite un bloque de código mientras se cumple una condición específica. Se utiliza cuando no se sabe de antemano cuántas veces se ejecutará el código.

## Conceptos Practicados

- **Estructura del while**: `while (condición) { código }`
- **Validación de condiciones**: evaluación de expresiones booleanas
- **Variables de control**: incremento y cambio de variables dentro del ciclo
- **Contadores y acumuladores**: conteo de ocurrencias y suma de valores
- **Análisis de números**: clasificación según propiedades matemáticas
- **Operadores de módulo**: para determinar múltiplos y números pares/impares

1. **EJ-1**: Clasificación de números negativos, positivos y múltiplos
2. **EJ-2**: Suma de dígitos y promedio de valores
3. **EJ-3**: Conteo de números pares e impares
4. **EJ-4**: Análisis de rango y límites
5. **EJ-5**: Cálculos matemáticos con validación
6. **EJ-6**: Agrupación y categorización de datos
7. **EJ-7**: Estadísticas de entrada de datos
8. **EJ-8**: Análisis de secuencias numéricas
9. **EJ-9**: Validación de condiciones múltiples

## Competencias Adquiridas

- Comprender cuándo usar while versus for
- Implementar condiciones de salida de ciclos
- Utilizar acumuladores para análisis de datos
- Aplicar operadores lógicos en condiciones
- Resolver problemas que requieren iteración condicional
- Manejar entrada de datos interactiva con prompt()
