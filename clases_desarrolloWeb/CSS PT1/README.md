Laura es una veterinaria, que quiere 
incursionar en la venta de productos para 
mascotas. 
Laura ya tiene un petshop y desea potenciar 
sus ventas.Para ello, necesita un sitio web en 
donde pueda mostrar sus productos y servicios 
(baño, peluquería, ropa, etc)
El público objetivo de Laura, se enmarca entre 
los 20 y los 65 años; para hombres y mujeres; 
interesados en una buena calidad de vida para 
sus mascotas.
La paleta de colores del local de Laura, está 
formado por tonalidades verdes y la tipografía 
para el logo, exclusivamente, de tipo Script.. 
El nombre del local es “Patas y Sonrisas”
Situación
De acuerdo a la descripción anterior, se pide: 
1) Indicar la paleta de colores 
correspondiente
2) La tipografía a usar (nombrar una fuente).
3) Laura, desea que elaboren la pagina 
principal, al menos con 3 o 4 elementos, 
que le servirá para tener una idea de cómo 
será el sitio que le desarrollarán. Los 
elementos son: Nombre del local (aplicarle 
la tipografía); 3 o 4 imágenes de productos 
y servicios (utilizar css para el diseño). 
Cada imagen deberá tener debajo una 
breve descripción); usar una barra de 
menú con un link a un formulario de 
registro y un contacto (número de teléfono
