# Introducción a HTML

## Descripción
Ejercicios prácticos que introducen los **fundamentos de HTML (HyperText Markup Language)** y las **etiquetas básicas** necesarias para crear páginas web.

## Conceptos Practicados

### Estructura Básica
- **Declaración DOCTYPE**: especificación de versión HTML
- **Elementos esenciales**: `<html>`, `<head>`, `<body>`
- **Metaetiquetas**: charset, viewport para responsividad
- **Título de página**: etiqueta `<title>`

### Etiquetas de Contenido
- **Encabezados**: `<h1>` a `<h6>` para jerarquía de títulos
- **Párrafos**: `<p>` para bloques de texto
- **Énfasis**: `<b>` (negrita), `<i>` (itálica), `<u>` (subrayado)
- **Líneas**: `<hr>` para divisiones
- **Saltos de línea**: `<br>`

### Elementos Multimedia e Hipervínculos
- **Imágenes**: etiqueta `<img>` con atributos src, alt, width, height
- **Enlaces**: `<a>` con atributos href, target
- **Atributos importantes**: align para alineación, bgcolor para colores de fondo

### Estructura Semántica
- **Listas**: `<ul>`, `<ol>`, `<li>` para contenido estructurado
- **Divisiones**: `<div>` para organización de contenido
- **Atributos globales**: id, class, style

## Archivos Incluidos

- **index.html**: Página principal del proyecto "Viaje Sol y Playa"
- **Tips.html**: Página de tips de viaje con diseño y multimedia
- **public/**: Carpeta con recursos (imágenes)

## Proyecto: Viaje Sol y Playa

Un proyecto completo que simula un sitio web de agencia de viajes, implementando:
- Estructura HTML semántica
- Uso de imágenes y multimedia
- Hipervínculos internos y externos
- Información de contacto y servicios
- Diseño básico con atributos HTML

## Competencias Adquiridas

- Escribir código HTML correcto y bien estructurado
- Comprender la diferencia entre presentación (atributos HTML) y estilos (CSS)
- Utilizar etiquetas semánticamente apropiadas
- Crear páginas accesibles con texto alternativo en imágenes
- Organizar contenido jerárquicamente
- Trabajar con rutas de archivos y recursos
- Implementar navegación básica entre páginas
