# Ciclo For

## Descripción
Ejercicios prácticos sobre la estructura de control **Ciclo For** en JavaScript.

El ciclo `for` es una estructura que permite repetir un bloque de código un número determinado de veces. Se utiliza cuando se conoce de antemano cuántas veces se debe ejecutar el código.

## Conceptos Practicados

- **Estructura básica del for**: `for (inicialización; condición; incremento)`
- **Iteración sobre secuencias**: recorrer rangos de números
- **Contadores y acumuladores**: uso de variables para contar y sumar valores
- **Condiciones dentro del ciclo**: if-else anidados dentro de for
- **Validación de condiciones matemáticas**: múltiplos, números pares/impares, rangos

4. **Ejercicio 4**: Operaciones matemáticas en ciclos
5. **Ejercicio 5**: Múltiplos y divisores
6. **Ejercicio 6**: Análisis de secuencias numéricas

## Competencias Adquiridas

- Comprender el flujo de ejecución de un ciclo for
- Utilizar variables de control para gestionar iteraciones
- Implementar lógica condicional dentro de ciclos
- Aplicar operadores matemáticos para validaciones
- Trabajar con acumuladores y contadores
