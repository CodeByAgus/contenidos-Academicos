This is the main content area. On desktop screens, the sidebar appears on the right side. On mobile devices, the sidebar moves below the main content thanks to the responsive design.

The layout uses flexbox to position the main content and sidebar side-by-side. The main content takes up most of the space (flex: 1 means it grows to fill available space), while the sidebar has a fixed width of 300px.

When the screen is smaller than 768px, the layout switches to a single column with the sidebar positioned below the main content using flex-direction: column on the page-container.
