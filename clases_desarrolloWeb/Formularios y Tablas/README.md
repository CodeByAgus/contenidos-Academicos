# Formularios y Tablas

## Descripción
Ejercicios prácticos sobre **Formularios HTML** y **Tablas HTML**. Estos son elementos fundamentales para capturar y mostrar datos en aplicaciones web.

## Conceptos Practicados

### Formularios
- **Elementos de entrada**: input (text, email), select, textarea
- **Etiqueta `<label>`**: asociación entre etiquetas y controles
- **Atributos importantes**: id, name, type, required, placeholder
- **Checkboxes y radio buttons**: selección múltiple y única
- **Botones de envío**: submit para procesar datos
- **Validación básica**: required, type="email"

### Tablas
- **Estructura básica**: `<table>`, `<tr>`, `<td>`, `<th>`
- **Encabezados**: uso de `<thead>`, `<tbody>`, `<tfoot>`
- **Atributos de formato**: border, cellpadding, cellspacing
- **Fusión de celdas**: rowspan, colspan
- **Estilos y alineación**: align, bgcolor
- **Datos complejos**: tablas con múltiples niveles de encabezados

## Competencias Adquiridas

- Crear formularios funcionales y accesibles
- Utilizar controles de formulario apropiados para cada tipo de dato
- Organizar datos en tablas legibles y bien estructuradas
- Aplicar estilos básicos a formularios y tablas
- Comprender la importancia de labels y atributos de validación
- Diseñar interfaces que faciliten la entrada de datos
